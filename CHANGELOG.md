# Changelog

## 0.2.0 - 2026-06-08

- Added `brief` cluster reports for PR comments, reviewer triage, and AI agent handoff.
- Added SARIF 2.1.0 cluster output for GitHub Code Scanning and quality dashboards.
- Updated the default `cluster` formats to include `brief`.
- Added package URL metadata.
- Expanded Chinese and English README documentation with brief and SARIF examples.

## 0.1.0 - 2026-06-08

- First public-ready release.
- Added offline JSONL/CSV ingestion with pass/fail inference.
- Added failure normalization, shingle fingerprint clustering, and anomaly detection.
- Added `cluster`, `sample`, `compare`, `init-config`, and `check` CLI commands.
- Added Markdown, JSON, CSV, and JUnit reporting.
- Added example datasets, GitHub Actions CI, and comprehensive unit tests.
